====================================================================
      《Nientum - CG与音乐剧场壁纸》安装与使用说明书
====================================================================

一、极简安装（只需 1 步）
--------------------------------------------------------------------
1. 解压压缩包到任意文件夹（无需提前手建目录）。
2. 双击运行根目录下的【一键安装壁纸.bat】。
3. 在弹出的安装窗口中点击【一键安装】即可！
   * 若当前解压路径含中文或空格，安装程序会自动帮您迁移至纯英文路径。
   * 安装程序会自动探测本机 Wallpaper Engine，自动配置联动并直接应用壁纸。
   * 提示：若杀毒软件拦截全局鼠标钩子或内置代理内核，请允许放行；
     程序仅本地运行（127.0.0.1:17988）用于转发桌面鼠标事件与网易云接口。

二、单独接入本地音乐（本包不含音频，可随时挂载或直接用网易云）
--------------------------------------------------------------------
1. 在安装时直接选定您的音乐文件夹，或安装完成后随时双击【接入本地音乐.bat】。
2. 支持两种接入方式：
   - 快捷挂载（推荐）：通过目录联接接入，不额外占用磁盘空间；
   - 完整复制：将音乐复制到壁纸目录下（Nientum_Wallpaper\音乐\）。
3. 支持智能识别：选择 `音乐` 文件夹、`media` 或独立播放器 `NientumPlayer_v2_UI` 根目录均可自动识别。
4. 不接入本地音乐也完全不影响使用：打开播放器切到「网易云音乐」扫码即可在线听歌。

三、桌面操作与核心功能说明
--------------------------------------------------------------------
1. 两种桌面播放形态（展开剧场 → 右上角「⚙ 设置 → 桌面播放格式」切换）：
   - 全屏壁纸：全屏欣赏静态 CG 或 4K 多层动态花海；右上角常驻可收起的黑金音乐胶囊（收起为旋转唱片悬浮球）。
   - 卡片播放：桌面居中 16:9 高清卡片（支持 60FPS 动态花海投影），底部提供无缝透明进度与控制栏、音频脚灯与旋转光环。
2. 左侧桌面信息栏（全屏壁纸与卡片模式均可使用，可在设置中单独开关）：
   - 左上角：双行大字体时钟（无衬底设计，与右侧胶囊顶部齐平）。
   - 中间：网易云竖排双语同步歌词。
   - 左下角：贴边快捷抽屉（点击箭头纯横向向右展开，展示选定文件夹下的 Windows 原生应用/文件图标；支持双击启动、长按 0.3 秒拖动排序、右边缘拖动调节抽屉宽度，点击抽屉外区域自动收起）。
3. 右侧桌面封票文件夹（可在设置中关闭）：
   - 鼠标移至屏幕最右缘展开封票列表，滚轮逐张居中滚动；
   - 双击封票打开对应 Windows 文件夹；鼠标悬停在封票左侧封面图 0.5 秒可在左侧展开文件夹预览窗（内部双击进入子目录或启动应用，长按封票可拖动调整顺序）。
4. 网易云音乐与断线重连：
   - 登录凭证仅保存在本机 Nientum_Bridge\cookie.json，支持 8 档音质与歌单搜歌；
   - 内置同音质同进度自动断线重连（网络抖动时自动刷新流链接并在原进度断点续播）；
   - 代理会复用 CDN 长连接，并把完整收完的歌曲写入本地缓存，二次播放与拖动进度不再走网络。
5. 失焦背景模糊：
   - 鼠标离开壁纸、停留在桌面图标/任务栏/右侧封票架/左侧状态栏或展开抽屉时，300ms 后背景壁纸自动柔和虚化，聚焦回桌面主区即恢复清晰（可在设置关闭）。

四、常用工具文件一览
--------------------------------------------------------------------
- 一键安装壁纸.bat  ：图形安装向导（推荐首发运行）。
- 接入本地音乐.bat  ：单独挂载/复制已有本地音乐文件夹。
- 卸载与清理.bat    ：停止后台桥接服务、移除开机联动项并安全断开音乐联接。
- Nientum_Bridge\    ：滚轮桥接器 + 网易云代理（单一 NientumBridge.exe，内置代理内核；ffmpeg 与安装器也在此目录）。
- Nientum_Wallpaper\：Wallpaper Engine 壁纸工程主体目录。

单 exe 说明：
- 首次安装会把内置代理内核解压到 Nientum_Bridge\runtime\（约 1 秒），之后启动不再解压；
- 用户数据（网易云登录 cookie、导入壁纸、图标缓存、歌词与播放缓存）都留在 Nientum_Bridge\；
- 网易云音频缓存位于 Nientum_Bridge\audio-cache\，最多 1 GB，可直接删除，不影响使用；
- 代理异常时看 Nientum_Bridge\proxy.log；桥接器异常时看 Nientum_Bridge\bridge.log。

五、新增：一键安装并启动与自检
--------------------------------------------------------------------
安装器默认只需点一次「一键安装并启动」，会自动安装、启动桥接器与网易云代理、启动并应用 Wallpaper Engine 壁纸。
完成后会显示桥接器 / 网易云代理 / Wallpaper Engine 三项状态；红色项可直接看日志路径或点「启动/重启桥接器」。

六、新增：导入其他壁纸
--------------------------------------------------------------------
进入「壁纸选图」→ 右上角「＋ 导入壁纸」。
- 支持本地 png/jpg/webp/gif/bmp 图片与 mp4/webm 视频，也扫描 Wallpaper Engine 库：视频壁纸动态导入；场景/网页/应用壁纸只导入作者提供的静态预览。
- 导入的媒体会复制到 Nientum_Bridge\imported-media，并去除视频音轨，只保留画面。H.264/VP8/VP9/AV1 只转封装、不重编码；HEVC/H.265/MOV 自动转 H.264（质量优先：保持原分辨率/帧率，CRF 14，4K60 较慢）。
- 导入记录在 Nientum_Bridge\imported-wallpapers.json；移除会删除工程内副本，不删除原始文件。
- 发布包默认排除 imported-media，基础包不会因个人导入变大；ffmpeg.exe 已随包，用于去音轨/转码。
- 更新后首次使用请重启一次桥接器（或重新运行安装器），让新版接口生效。

七、新增：直接输入与每日推荐
--------------------------------------------------------------------
- 搜索框、帧率输入框、抽屉筛选/重命名等文本框，点击后会在原位置弹出原生输入框；可直接用键盘/输入法输入，Enter 确认，Esc 取消。
- 网易云播放模式的循环按钮新增“每日推荐”：需要先登录网易云，选中后自动拉取每日推荐并播放；切回歌单或搜索时会回到列表循环。
- 若原生输入框不弹出或无法输入，检查 Nientum_Bridge\bridge.log 中 native input show 一行的 fg/attached/focus；新版日志应能看到 attached=True、focus=True。
- 导入视频请使用 H.264 MP4 或 WebM（VP8/VP9）；HEVC/H.265 网页内核不支持，会在导入时明确报错，已有 HEVC 项会标“编码不支持”。
- WE 场景/网页/应用壁纸只能导入作者提供的预览图，分辨率由作者决定（本次示例仅 254×254，所以会糊）；动态背景请用 WE 视频壁纸或本地视频。
- WE 场景壁纸要动态：在 WE「已安装」右键该壁纸 →「在窗口中播放」，用 OBS/Windows Game Bar 录 10–20 秒（隐藏鼠标），把 MP4 作为本地视频导入；网页壁纸无法直接运行 scene.pkg。
- 导入时弹窗会显示百分比进度：去音轨/复制 → H.264 转码 → 生成 1080p VP9 兼容版 → 缩略图/入清单。
- 视频用独立 DOM 视频层播放；若 H.264 在 WE 中解码失败或卡住，会自动切到 VP9 兼容版，再失败则显示缩略图而不是黑屏。
